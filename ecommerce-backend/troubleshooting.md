## Copy the Error Into an AI Assistant

1. If you encounter an error, copy and paste it into an AI assistant and ask what it means.
2. If you do not understand the explanation, ask for more detail.
3. You can ask the AI assistant to try to fix the error. Review its changes and make sure they make sense.
4. For the best learning experience, first ask about the error and understand what it means. Then ask for help fixing it.
5. If the problem continues, consult the tutorial repository that inspired this backend for additional context and compare its setup with this project.
